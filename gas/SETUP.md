# 無料相談 予約カレンダー連携（Google Apps Script）設定手順

booking.html の予約フォームを、あなたの Google カレンダーとつなぎます。
これを行うと **カレンダーに予定がある時間帯の前後3時間は、自動で予約不可** になります。
予約ページが開かれるたびに最新のカレンダーを読むので、常に最新の状態が反映されます（常駐監視は不要です）。
さらに、予約が入ると **お客様とあなたの両方に、日時＋Google Meet の URL 入りメール** が届きます。

所要時間：約10分。プログラミングの知識は不要です。

---

## ⭐ 予約メール（Google Meet URL付き）を有効にする

`Code.gs` の `CONFIG` で、次の2つを設定してください。

1. **`NOTIFY_EMAIL`** … あなたのメールアドレス。→ 予約が入るとあなたにも通知が届きます。
   例：`NOTIFY_EMAIL: 'you@example.com',`

2. **`FIXED_MEET_URL`** … 使い回せる Google Meet のリンク（おすすめ・簡単）。
   - 取得方法：https://meet.google.com を開く →「新しい会議を作成」→「**後で使用する会議リンクを作成**」
   - 出てきた `https://meet.google.com/xxx-xxxx-xxx` を貼り付け。
   - 例：`FIXED_MEET_URL: 'https://meet.google.com/abc-defg-hij',`
   - ※ 予約は前後3時間空くので、固定リンクでも予約同士がかぶりません。

これで、確認メールに毎回この Meet URL が入ります。設定後は必ず「デプロイを管理 → 新しいバージョン」で再デプロイしてください。

（上級・任意）予約ごとに**別々のMeetリンク**を自動生成したい場合は、`AUTO_CREATE_MEET: true` にし、
Apps Script 左メニュー「サービス（＋）」→「**Google Calendar API**」を追加してから再デプロイします。

---

## 1. Apps Script プロジェクトを作る

1. パソコンで https://script.google.com を開く（相談で使う Google アカウントでログイン）。
2. 「新しいプロジェクト」をクリック。
3. 最初から入っている `Code.gs` の中身をすべて消し、
   このフォルダの **`Code.gs` の中身をまるごとコピーして貼り付け**。
4. 左上のプロジェクト名を「MIRACO 予約」などに変更。

## 2. 設定（CONFIG）を自分用に直す

貼り付けた `Code.gs` の上のほうにある `CONFIG` を確認します。基本はそのままでOKですが、必要なら変更します。

| 項目 | 説明 | 初期値 |
|------|------|--------|
| `CALENDAR_ID` | 使うカレンダー。メインならそのまま | `'primary'` |
| `BUFFER_MINUTES` | 予定の前後、何分を予約不可にするか（3時間＝180） | `180` |
| `SLOT_MINUTES` | 相談1回の長さ（分） | `30` |
| `WEEKDAY_SLOTS` / `WEEKEND_SLOTS` | 予約できる時間。**booking.html と必ず同じにする** | 平日18/21時, 土日10/15/20時 |
| `NOTIFY_EMAIL` | 予約が入ったら通知を受け取るメール（任意） | 空 |
| `SHEET_ID` | 予約を記録するスプレッドシートID（任意） | 空 |

> 予約可能な時間そのものを変えたいときは、`Code.gs` の `WEEKDAY_SLOTS`/`WEEKEND_SLOTS` と、
> `booking.html` の `CONFIG.weekdaySlots`/`weekendSlots` の **両方** を同じ値に直してください。

## 3. ウェブアプリとして公開（デプロイ）

1. 右上の「デプロイ」→「新しいデプロイ」。
2. 歯車（種類の選択）→「ウェブアプリ」。
3. 設定：
   - 説明：任意（例：MIRACO予約v1）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」→ 初回は Google の権限確認が出るので、自分のアカウントで **許可**。
   （「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」で進めてOK。自分が作ったスクリプトです）
5. 表示される **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピー。

## 4. booking.html に URL を貼る

`booking.html` の JavaScript 内、`CONFIG` の

```js
GAS_URL: 'YOUR_GAS_WEB_APP_URL',
```

を、手順3でコピーした URL に置き換えて保存 → コミット＆デプロイ。

```js
GAS_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

## 5. 動作確認

1. 本番（または deploy preview）の `/booking.html` を開く。
2. 適当な日を選び、カレンダーにわざと予定を入れた日/時間帯で、
   その前後3時間のスロットが「×（取り消し線・選択不可）」になっていれば成功。
3. 予定のない日は通常どおり選べます。

## よくある質問

**Q. 私が見張っていなくても、常に反映されますか？**
はい。予約ページを開くたびに、その瞬間のカレンダーを読みます。予定を足したり消したりすれば、次に誰かがページを開いた時点で自動的に反映されます。

**Q. 予約が入ったら、その時間も自動でふさがりますか？**
`CREATE_EVENT_ON_BOOKING: true`（初期値）なら、予約と同時にカレンダーへ予定を作るので、その予約の前後3時間も自動で予約不可になります。

**Q. 時間帯（18時・21時など）を変えたい**
手順2の表を参照。`Code.gs` と `booking.html` の両方を同じ値に。

**Q. 連携をやめたい**
`booking.html` の `GAS_URL` をプレースホルダに戻すと、カレンダーを見ずに全スロット表示に戻ります（予約の記録もされません）。
